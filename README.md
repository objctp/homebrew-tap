# Objctp Tap

## How do I install these formulae?

`brew install objctp/tap/<formula>`

Or `brew tap objctp/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "objctp/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
